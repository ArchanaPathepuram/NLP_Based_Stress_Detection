# 🧠 Stress Detection using NLP and Bidirectional LSTM

## Overview

This project predicts whether a given text expresses **Stress** or **No Stress** using Natural Language Processing and a Bidirectional LSTM deep learning model.

## Features

- Text preprocessing
- Stopword removal
- Lemmatization
- GloVe word embeddings
- Bidirectional LSTM model
- Streamlit web application
- Real-time prediction

## Technologies Used

- Python
- TensorFlow
- Streamlit
- NLTK
- NumPy
- Scikit-learn

## Dataset

Stress.csv

## Model

- Bidirectional LSTM
- GloVe Embedding (100 Dimensions)

## Accuracy

71.25%

## Run the Application

```bash
streamlit run app.py
```
